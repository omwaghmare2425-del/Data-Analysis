# Week 2 – Advanced Data Visualization and Storytelling with Python

## 📌 Project Overview

This project focuses on Advanced Data Visualization and Data Storytelling using Python. 
The Titanic dataset is used to analyze passenger survival patterns and present meaningful 
insights through clear and effective visualizations.

The main goal is to convert raw data into an easy-to-understand visual story for both 
technical and non-technical audiences.

## 📊 Dataset

**Dataset:** Titanic Cleaned Dataset

The dataset contains passenger information such as:

- Survival status
- Passenger class
- Gender
- Age
- Fare
- Embarkation details

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook / Python
- Microsoft Word (Documentation)

## 📈 Visualizations Created

The project includes 5 visualizations:

1. Survival Distribution
2. Survival by Gender
3. Survival by Passenger Class
4. Age Distribution by Survival
5. Age vs Fare and Survival

Each visualization is supported with explanations and insights to build a clear data story.

## 🔍 Key Insights

- Survival outcomes were not equally distributed among passengers.
- Gender shows a noticeable difference in survival outcomes.
- Passenger class is strongly associated with survival.
- Age provides useful demographic information about survival patterns.
- Fare and age together help identify additional patterns in the dataset.

## 🎯 Objective

The objective of this project is to demonstrate how advanced data visualization techniques 
can be used to identify trends, compare groups, discover patterns, and communicate insights 
effectively.

## 📁 Project Files

- `titanic_cleaned.csv` – Dataset used for analysis
- `Week_2_Advanced_Data_Visualization_Titanic.docx` – Detailed project documentation
- Visualization files – Charts generated during the analysis

## ✅ Conclusion

This project demonstrates the importance of data visualization in transforming raw data 
into meaningful information. By combining multiple visualization techniques with data 
storytelling, complex patterns can be communicated in a simple and understandable way.
